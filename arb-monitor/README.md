# SELF-ROOT BTC Arb Monitor

A tiny public preview service for matching Kalshi and Polymarket US 15-minute BTC BRTI contracts.

- Dynamically finds the current open contracts.
- Verifies matching window and benchmark.
- Reads both order books.
- Estimates fee-adjusted two-leg outcomes for a 4-contract test size.
- Does **not** execute trades.

Founder access is sold through a dedicated Stripe Payment Link.
