# Developmental Construction Grammar v1 — Result

**Date:** 2026-09-29  
**Status:** immutable experiment record

## Result

Three seeds.

```text
old language before development          100%
unseen recursive wrapper compositions    100%
one-shot new SET construction reuse      100%
one-shot new ASK construction reuse      100%
old language after tentative additions   100%
new constructions after confirmation     100%
old language after confirmation          100%
```

All one-shot evaluation reused the novel construction with semantic attributes not present in its grounding example and with disjoint OOV argument strings.

Four wrapper constructions were induced from paired grounded examples and successfully composed at depth 2–3 despite nested wrapper combinations never appearing during training.

## Interpretation

In the controlled language regime, explicit construction objects support immediate local language growth without global retraining or catastrophic forgetting.

This does not establish open-domain semantic acquisition, ambiguity resolution, pragmatic inference, or scalable matching.
